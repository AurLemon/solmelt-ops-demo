# 项目文档

用途：保存架构、接口、事件、数据库归属、环境、协作和 AI 规范。

允许：与仓库代码和任务书同步的事实。禁止：记录未确认的接口、虚构完成状态或替代 `.requirements` 原始资料。

入口：`environment-setup.md`、`acceptance-baseline.md`、`architecture.md`、`api-contract.md`。

AI 协作入口：新成员先读 `agent-quickstart.md`，周四现场按 `ai/thursday-workshop.md` 的四阶段 Prompt 逐步执行，各领域细节以 `ai/auth.md`、`ai/device.md`、`ai/telemetry.md`、`ai/dashboard.md` 为准，完成后按 `module-validation.md` 留存真实验收反馈。
