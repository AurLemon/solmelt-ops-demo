# AI 工作说明

用途：四组可直接复制给 AI 的领域任务提示词、周四课堂逐步执行手册，以及独立 AI Review 规范。提示词按业务领域分工，不把 Agent 锁死在单个文件夹；Agent 可以跨目录阅读，但只能写入领域私有目录。

首次课堂开发使用 [周四课堂执行手册](thursday-workshop.md)。该手册把每组任务拆成 A/B 两个 checkpoint 和四段式 Prompt；`auth.md`、`device.md`、`telemetry.md`、`dashboard.md` 继续作为领域完整边界和周五补齐最低验收时的长期说明。

允许：明确范围、最低验收、禁止事项和交付格式。禁止：把提示词写成跨领域授权或让 AI 自行扩展需求。
