# 领域词汇与口径

| 词汇     | 固定定义                                                               |
| -------- | ---------------------------------------------------------------------- |
| 产品     | 一类设备的属性模板；本项目只有标识为 `Z60KbveZzXk8` 的立式熔盐泵产品   |
| 设备     | 产品的具体实例，共 9 台，编号和名称来自老师提供的物模型                |
| 冷盐泵   | `20WSC10AP010` 至 `20WSC10AP040`，负责充热流程                         |
| 调温泵   | `20WSC10AP050`、`20WSC10AP060`，负责温控                               |
| 热盐泵   | `20WSH20AP010` 至 `20WSH20AP030`，负责发电流程                         |
| 启用     | 设备允许接收数据；停用设备的上报必须被拒绝                             |
| 在线     | 未删除且最近 300 秒内存在成功上报                                      |
| 运行中   | 在线且最新 `inverter_start_status` 为 `true`                           |
| 数据延迟 | 全局或设备最新成功上报距当前超过 60 秒                                 |
| 数据截至 | 当前视图使用的最新一条真实数据时间，不使用页面刷新时间代替             |
| 预警     | 指标达到第一风险级别，页面提示但仍保留处理时间                         |
| 严重报警 | 指标达到必须立即处理的风险级别                                         |
| 模拟数据 | Python 脚本按领域量级生成的测试输入，是任务规定的数据源，不是页面 Mock |

## 基础报警阈值

| 指标               | Identifier                 | 阈值         |
| ------------------ | -------------------------- | ------------ |
| 电机驱动端轴承温度 | `motor_drive_bearing_temp` | `> 65 ℃`     |
| 泵振动 X 轴        | `pump_vibration_x`         | `> 4.5 mm/s` |
| 变频器电流         | `inverter_current`         | `> 60 A`     |

所有接口传输 UTC ISO 8601 时间；页面按 Asia/Shanghai 显示。
