# 监测大屏领域

## 允许范围

本领域实现默认写入 `layers/dashboard/**`，固定分支为 `feat/dashboard`；Agent 可以阅读全仓库追踪数据流，但不得修改公共契约、Schema、migration、依赖、根配置或其他 Layer。上述公共面由组长维护。

## 必须实现

- 1920×1080 暗色大屏并支持自适应缩放。
- 至少六张统计卡、设备实时状态、近期报警滚动列表。
- 30 秒内轮询一次实时数据。
- 显示数据截至时间；最新数据超过 60 秒时明确标记延迟。

## 不可变规则

- 大屏是只读消费者，不创建业务表，不修改设备、时序或报警数据。
- API 使用 `/api/v1/dashboard/*`，返回 `DashboardOverview` 等冻结契约。
- 在线、运行中、报警和延迟口径必须来自 `docs/domain-glossary.md`。
- 不得在页面中生成随机数据，不得直接 import 其他 Layer 的 Service。
- 可使用 ECharts，但不得引入新的图表库。
- 健康评分、复杂运行模式、WebSocket、地图和 3D 均为可选项；最低验收完成且组长批准前不得实现。

## 验收

上报数据后卡片、设备状态和报警更新；模拟器停止后数值保持最后一次真实数据，同时出现延迟标记。
