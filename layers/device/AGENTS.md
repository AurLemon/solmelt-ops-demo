# 物模型与设备领域

## 允许范围

本领域实现默认写入 `layers/device/**`，固定分支为 `feat/device`；Agent 可以阅读全仓库追踪数据流，但不得修改公共契约、Schema、migration、依赖、根配置或其他 Layer。上述公共面由组长维护。

## 必须实现

- 产品列表与立式熔盐泵产品管理。
- 导入并展示 30 个物模型属性。
- 9 台设备的列表、详情、编辑、逻辑删除、启用和停用。
- 最新属性值与数据时间；未上报显示 `—`。
- 根据最后上报时间派生在线状态。

## 不可变规则

- `.requirements/学生复现-物模型.zip` 是设备和属性的唯一事实源。
- 产品标识固定为 `Z60KbveZzXk8`，不得改写设备编号、名称、属性标识或单位。
- 在线窗口固定为 300 秒，状态只允许 `ENABLED` 和 `DISABLED`。
- API 使用 `/api/v1/device/*`，响应必须使用统一 `ApiResult<T>`。
- 可只读 Telemetry 拥有的 `DeviceLatestValue` 冻结投影以展示最新值；不得写入该投影，不得调用或 import Telemetry 私有 Service。

## 验收

系统正确展示 1 个产品、30 个属性和 9 台设备；设备启停与逻辑删除生效；最新数据与在线状态口径一致。
